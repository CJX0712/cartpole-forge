# CartPole Forge · PPO 强化学习实验室

单文件、零依赖、离线可跑的 PPO 强化学习实验室。浏览器直接打开 `index.html` 即可观看
智能体用学到的策略平衡倒立摆。从零手写全部组件：CartPole 物理、策略/价值双网络、
GAE 优势估计、PPO 裁剪代理目标、熵正则、Adam，约 350 行纯 JS。

## 它做什么

- **环境**：gym 经典 CartPole-v1 动力学（重力 9.8 / 推力 ±10 / τ=0.02，|x|>2.4 或 |θ|>12° 终止）
- **智能体**：策略网络 4→16→2（softmax，左/右推）+ 价值网络 4→16→1
- **算法**：完整 PPO —— 每轮采 ~800 步 rollout，GAE(γ=0.99, λ=0.95) 优势归一化，
  4 个 epoch 的裁剪代理目标（ε=0.2）+ 价值回归（×0.5）+ 熵奖励（×0.01）
- **演示**：Canvas 动画实时播放贪心策略，动作概率条 + 价值估计实时显示，回报曲线

## 可验证不变量（`_smoke.js`，Node 无头全绿）

1. **物理确定性**：同状态同动作 → bit 级同结果；|x|/|θ| 终止条件精确触发；无外力时杆失稳（|θ| 增长）
2. **GAE 双路径对拍**：递推式 vs 暴力展开定义，20 组随机序列（含 done 掩码）全等 < 1e-10
3. **梯度检验**：PPO 裁剪目标 + 价值回归 + 熵正则的解析梯度 vs 中心差分 < 1e-5
4. **训练确定性**：同种子两次训练，双网络参数 bit 级相等
5. **学会平衡**：训练 200 迭代后贪心评估平均存活 > 150 步（上限 200），随机基线 < 50 步，≥ 3× 提升
6. **回报曲线上升**：末 10 迭代均值 > 2× 首 10 迭代
7. 边界：maxSteps 封顶、reset 边界 ±0.05、概率归一

## 运行测试

```bash
node _smoke.js    # 引擎不变量
node _probe.js    # 学习曲线/评估/策略行为扫描（生成 _probe.txt）
node _uicheck.js  # DOM stub 下点遍全部 UI 控件
```

## 原理一图流

```
状态 s(4维) → π(a|s) → 动作 → 环境 → r, s'
                ↓
GAE: A_t = Σ(γλ)^l δ_{t+l},  δ_t = r_t + γV(s_{t+1}) − V(s_t)
PPO: max min(r·A, clip(r,1±ε)·A) + c_v·V回归 + c_e·H(π)
```
